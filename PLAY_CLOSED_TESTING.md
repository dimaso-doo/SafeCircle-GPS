## Test behavior

The closed-test build uses `CLOSED_TEST_FULL_ACCESS=true` so reviewers and
approved testers can exercise premium-gated screens without a live store
subscription. This flag must be disabled for the production release.

Location sharing remains disabled until the user explicitly starts it.
Background sharing requires a separate opt-in and remains visibly indicated.
